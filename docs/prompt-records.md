# Prompt 记录

## 用户原始任务

```text
帮我按照作业要求完成作业
```

用户提供的作业文件为 `/Users/apple/Downloads/期末作业.pdf`。读取作业要求后，确定本次需要完成一个有安全控制点的实质性代码修改，并提交配套过程材料。

## 关键 Prompt 1：确定实现方向

```text
按照期末作业要求，在已有仓库中选择一个模块完成安全相关的实质性修改。
要求不要只改 README，要涉及输入处理、身份认证、权限判断、数据存取或错误响应等安全控制点。
请优先选择改动边界清晰、能运行验证的方案，并补齐 docs/ 和 reports/ 下的过程材料。
```

### 安全约束进入方式

- 明确要求不能只改文档。
- 明确要求安全控制点落在身份认证、权限判断和数据存取上。
- 明确要求过程材料可追溯。

## 关键 Prompt 2：实现认证加固

```text
为 Flask 桌面宠物待办模块增加本地登录保护。
约束：
1. 待办数据接口必须登录后才能访问。
2. 访问密码必须从 PET_TODO_PASSWORD 环境变量读取，不能硬编码。
3. 不要把密码存储到浏览器 localStorage 或 sessionStorage。
4. 未登录访问返回 401，错误密码返回 401。
5. 保持原有待办功能行为不变。
6. Flask debug 模式默认关闭。
```

### AI 生成结果中的安全相关片段

- 后端新增 `login_required` 装饰器，对待办数据接口统一做认证检查。
- 后端通过 `configured_password()` 从 `PET_TODO_PASSWORD` 环境变量读取访问密码。
- 使用 `hmac.compare_digest()` 比较登录密码，避免普通字符串比较带来的细节泄露。
- 前端只在登录表单中提交密码，不保存密码到浏览器持久存储。

## 发现偏差或问题时的交互记录

初始思路中存在使用演示默认密码的可能性，但这会违反“禁止硬编码凭据”的约束，因此最终改为必须通过 `PET_TODO_PASSWORD` 环境变量配置。未配置时，登录接口返回 `503` 并提示设置环境变量。
