# 项目约束文档

## 背景说明

当前仓库包含多个信息安全课程实践模块。本次修改对象是 Flask 实现的桌面宠物待办清单。该模块会读写本地 `data/state.json`，其中可能包含用户的个人待办内容。

## 任务范围

- 为桌面宠物待办清单增加本地登录保护。
- 保护所有读取或修改待办数据的 JSON API。
- 更新 README 和作业过程材料。
- 不引入复杂数据库或第三方认证系统。

## 安全约束

- 不允许在代码、README 示例或提交记录中写入真实密码、密钥或 Cookie。
- 访问密码必须通过 `PET_TODO_PASSWORD` 环境变量读取。
- 未登录访问待办数据接口必须返回 `401`。
- 登录接口不得泄露正确密码、环境变量值、本地文件路径或异常堆栈。
- 保持 Flask debug 模式默认关闭，只能通过显式环境变量临时开启。
- 前端只能把密码发送到登录接口，不得写入 localStorage 或 sessionStorage。
- 安全控制必须落在后端接口层，不能只依赖前端隐藏按钮或页面。

## 禁止行为

- 禁止硬编码默认管理员密码。
- 禁止把认证判断只写在 JavaScript 中。
- 禁止将 `.env`、密钥、证书、本地数据库等敏感文件提交到仓库。
- 禁止为通过测试而绕过登录检查。

## 验收条件

- 未登录请求 `GET /api/state` 返回 `401`。
- 设置 `PET_TODO_PASSWORD` 后，正确密码可以登录，错误密码返回 `401`。
- 登录后可以正常新增、完成、删除待办。
- 登出后再次访问待办接口返回 `401`。
