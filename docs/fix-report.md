# 整改说明与验证记录

## 问题是什么

桌面宠物待办模块原本所有接口均可直接访问。只要知道接口路径，未登录用户就可以读取 `data/state.json` 中的待办内容，或通过接口新增、修改、删除任务。

这属于缺少身份认证和访问控制的问题。

## 怎么改

- 新增 `PET_TODO_PASSWORD` 环境变量作为本地访问密码来源。
- 新增 `/api/login`、`/api/logout`、`/api/session` 三个会话接口。
- 新增 `login_required` 装饰器，对待办数据接口统一做后端认证检查。
- 前端新增登录面板，未登录时不加载待办数据。
- README 补充运行方式、安全说明和验证方式。

## 改完应满足什么条件

- 未登录访问待办数据接口返回 `401`。
- 未配置 `PET_TODO_PASSWORD` 时不能绕过登录。
- 正确密码登录后可以正常使用原有待办功能。
- 登出后会话失效，再次访问待办接口返回 `401`。
