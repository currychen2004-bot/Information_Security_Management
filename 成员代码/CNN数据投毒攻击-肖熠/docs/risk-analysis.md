\# CNN 模型预测接口安全风险分析报告



\*\*负责人：\*\* 肖熠

\*\*涉及模块：\*\* 新增的 CNN 模型加载与预测对外接口 (`predict\_api.py`)



\## 一、 业务背景说明

在完成 CNN 数据投毒训练后，为了验证模型的脆弱性或提供对外服务，本次使用 AI 辅助开发了一个全新的\*\*“模型预测接口”\*\*。该模块的核心功能是接收外部传入的模型文件名，在服务器本地找到该模型并使用 PyTorch 加载，随后进行预测。



\## 二、 核心安全风险识别

由于涉及到加载外部指定的文件，该模块在未经安全加固时面临极高的安全威胁：



\### 1. 任意代码执行漏洞 (Pickle RCE) - 【高危】

\* \*\*风险机制：\*\* PyTorch 原生的 `torch.load()` 函数底层依赖于 Python 的 `pickle` 序列化机制。

\* \*\*攻击路径：\*\* 如果系统加载了一个被黑客恶意篡改的 `.pth` 模型文件，由于反序列化过程的特性，黑客可以构造恶意类（如重写 `\_\_reduce\_\_` 方法），从而在目标服务器上直接执行任意系统命令（例如反弹 Shell 或删除系统文件）。



\### 2. 目录穿越攻击 (Path Traversal) - 【高危】

\* \*\*风险机制：\*\* 接口接收用户传入的文件名（`model\_filename`）后，如果直接将其与基础路径拼接，会引发越权访问。

\* \*\*攻击路径：\*\* 攻击者可以利用相对路径符号构造恶意载荷，如输入 `../../../../etc/passwd` 或 `../../../.ssh/id\_rsa`。系统将跳出预设的模型文件夹，越权读取服务器上的核心敏感文件。



\### 3. 非法文件类型加载 - 【中危】

\* \*\*风险机制：\*\* 缺乏严格的文件扩展名校验。

\* \*\*攻击路径：\*\* 攻击者可能传入非模型文件（如 `.sh`, `.exe` 或超大无效文件），导致模型解析引擎崩溃，进而引发应用的拒绝服务 (DoS)。
